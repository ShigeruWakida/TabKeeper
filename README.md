# TabKeeper

Chrome拡張機能（Manifest V3）。現在の**1ウィンドウ**のタブ構成をJSONファイルに保存し、必要なときに新しいウィンドウへ復元します。

## 機能

- タブのURL、並び順、ピン留め状態、選択中のタブを保存・復元
- 保存先はローカルJSONファイル（名前はダウンロード時に指定可能）
- JSONを選択して新しいウィンドウに復元
- 元のウィンドウ・タブは変更しない
- 手動保存のみ。複数ウィンドウの一括管理、タブグループ復元、自動保存、外部送信はありません

## インストール

1. リポジトリをZIPでダウンロードして展開します
2. Chromeで `chrome://extensions` を開きます
3. 「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」で `manifest.json` のあるフォルダーを選択します
5. ツールバーにTabKeeperを固定し、「保存」「復元」を使用します

## 制限

- 安全かつ確実に復元できる `http:` / `https:` のタブだけ復元します。`chrome://` や `file://` はJSONに記録されても復元時に除外します
- タブグループの情報、ログインセッション、フォームの入力途中の値、ページ内スクロール位置は保存しません
- Chromeではピン留めタブは通常タブよりも左側に配置されます
- JSONには個人的なURLが含まれるため、バックアップのJSONを公開リポジトリにコミットしないでください

## テスト

Node.jsの環境で `node --test tests/session.test.cjs` を実行します。
