# TabKeeper

Chrome Manifest V3拡張機能。現在の**1ウィンドウ**のタブURL・並び順・固定状態・選択タブをJSONに保存し、新しいウィンドウへ復元します。

## v1.1.0 の変更点

- 初回に「保存先フォルダーを選択・変更」でフォルダーを指定し、そのフォルダーのハンドルをIndexedDBに記憶
- 以後は同じフォルダーへ直接保存（Chromeの権限が失効した場合、保存時に再許可が必要）
- 保存名はローカル日時の秒までを使う `TabKeeper-YYYYMMDD-HHMMSS.json`
- 同じ秒にファイル名が重複した場合、`-001`、`-002`…を付けて既存のバックアップを上書きしない
- ChromiumのFile System Access API（`showDirectoryPicker`）が必要。Chromeの設定・ポリシーによっては使えない場合があります

## 操作

1. Chromeで `chrome://extensions` を開き、デベロッパーモードをオンにします
2. このリポジトリをダウンロード・展開し、`manifest.json` のあるフォルダーを「パッケージ化されていない拡張機能を読み込む」で選びます
3. TabKeeperを開き「保存先フォルダーを選択・変更」で保存先を指定します
4. 「現在のタブをJSONに保存」でバックアップします
5. 復元は従来どおりJSONファイルを選択して「新しいウィンドウに復元」を押します

## 制限事項

- 保存先フォルダーの**名前**を表示します。ブラウザーの仕様により絶対パスは取得しません
- プロファイルを変更・削除した場合、拡張機能の保存情報が消えた場合、フォルダーが移動・削除された場合には再設定が必要です
- `http://` / `https://` 以外のURL（`chrome://`、`file://` 等）はJSONに含まれても復元時にスキップします
- タブグループ、複数ウィンドウ、フォーム入力内容、スクロール位置、ログイン情報は保存・復元しません
- JSONには個人的なURLが含まれます。公開リポジトリへアップロードしないでください
